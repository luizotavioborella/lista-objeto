# 🧩 JavaScript Objects

A collection of exercises developed with HTML and JavaScript to practice objects, methods and basic programming logic.

These activities were created during the Systems Development course at SENAI to reinforce the use of JavaScript objects, properties, methods, arrays, conditions and user interaction.

## ✨ Exercises

The repository contains 15 exercises involving:

- Student grade average and approval
- Product price and quantity calculation
- Bank account deposit and withdrawal
- Age calculation
- Salary increase calculation
- Car fuel consumption
- Restaurant service fee calculation
- Pokémon attack and damage system
- Product inventory management
- Movie duration and age rating
- Shopping cart discount calculation
- Social media profile management
- Virtual farm management
- Veterinary hospital system
- Voting system
